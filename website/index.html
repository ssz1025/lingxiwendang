本地知识库
我们为什么选择本地优先的存储方案？
选择本地优先主要有三个原因：
1. 数据归属清晰，文档始终在你的磁盘上；
2. 可迁移，纯文本文件不依赖任何特定平台；
3. 隐私可控，索引与检索无需上传云端。
引用自《架构设计.md》
那如何备份整个知识库？
直接复制根目录即可，或在应用内使用「导出知识库」生成完整压缩包；也可以用 Git 做版本化备份，每次修改都有记录。
